# แผนที่การอ่าน 15 บท → NewData

สรุปว่าแต่ละบท แต่ละช่อง อ่านอย่างไร และดึงข้อมูลจาก NewData group ไหน

อ้างอิงโค้ด:
- โครงหัวข้อย่อย (bullets) ต่อบท: [chapter-outline.ts](../src/lib/bazi/chapter-outline.ts)
- แผนที่ช่อง → resolver → group: [chapter-newdata-map.ts](../src/lib/bazi/chapter-newdata-map.ts)
- ฟังก์ชันคำนวณคีย์ + ดึง row: [newdata-lookup.ts](../src/lib/bazi/newdata-lookup.ts)

## กลไกหลัก (เหมือนกันทุกบท)

```
ดวง (4 เสา + กำลังดิถี)  →  resolveChapterBoxes(บท, facts, NewData map)
        │
        ├─ แต่ละบทมี "หัวข้อย่อย (bullets)" คงที่ → 1 bullet = 1 กล่อง
        ├─ แต่ละกล่องมี Resolver[] บอกว่าจะดึง NewData group ไหน คีย์อะไร
        └─ Resolver → matchXxx() → คำนวณคีย์จากดวง → ดึง row จาก group
```

Resolver คำนวณคีย์จากดวงเอง (ก้านวัน / กิ่งเดือน / กำลังดิถี / ปฏิกิริยาธาตุ) แล้ว lookup ใน group ที่ระบุ — ถ้ามี row คืนข้อความ, ถ้าไม่มี = กล่องว่าง รอซินแสเติมในตัวแก้ PDF

สถานะของแต่ละช่อง (คอลัมน์ "ดึงจาก"):
- ✅ มีข้อมูล = map กับ group ที่มีเนื้อหาในคลังแล้ว
- ⚠️ รอเติม = map กับ group แล้ว แต่ group นั้นยังว่าง (ต้องเติมเนื้อหา)
- ❌ ไม่มี (ขาด) = ช่องนี้ไม่ได้ map NewData เลย → เป็นช่องเปล่าให้ซินแสเขียนเองในตัวแก้ PDF
- ⭐ = บท 1 ช่อง "กำลังดิถี" (กรอก 50 แบบ 2026-06-25)
