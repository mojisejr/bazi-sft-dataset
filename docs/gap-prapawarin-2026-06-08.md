# Gap-analysis: engine vs input (เคส ประภาวรินท์ 1986-09-16) — Phase 1

ดวง: 1986-09-16 14:23 หญิง · engine คำนวณ: **ดิถี 癸**, 4 เสา **丙寅 / 丁酉 / 癸亥 / 己未**, strengthScore **2.75 → band "ดวงอ่อน"**

## ภาพรวม
engine **ครอบคลุมครบ 15 ข้อ + bonus ข้อ 16 (speech)** โครงสร้าง/หัวข้อตรงกับ input · มี marker เชี่ยงแซ/อักษรจีน/วัยจร/อายุครบเกือบหมด → **ไม่ใช่ปัญหา coverage** ปัญหาหลักคือ **"ธาตุ useful-god ที่ engine เลือก ต่างจากซินแส"** ซึ่ง cascade ไปหลายข้อ

## 🔴 Root cause: useful-god / เสริมดวง elements ต่างกัน
| | engine | ซินแส (input) |
|---|---|---|
| band | ดวงอ่อน (2.75, กลางโซน weak) | "อ่อนแต่ไม่มาก / เกือบสมดุล" |
| ธาตุเสริมดวง (ข้อ1) | ทอง + น้ำ (resource+คู่ธาตุ) | **ไม้ + ทอง** |
| อาชีพ useful (ข้อ2) | ทอง + น้ำ | **ไฟ + ทอง** (ไฟ=โชคลาภ) |
| เลี่ยง (ข้อ2) | ดิน ✓ | ดิน ✓ (ตรง) |
| สี/ทิศ (ข้อ14) | ทอง→ขาว, ทิศตะวันตก/เหนือ/ใต้ | ไฟ/ไม้→แดง+เขียว, ทิศเหนือ/ตะวันออก |
| องค์เทพ (ข้อ15) | เจ้าแม่ทับทิม(น้ำ)เป็นหลัก | **ทีกง**เป็นหลัก + จตุโลกบาล(ธตรฐ/วิรูปักข์/วิรุฬหก)+เตาไฟ+กวนอู |

**สาเหตุ:** engine อ่านเป็น "ดวงอ่อนกลาง ๆ" → สั่งเสริมด้วย resource(ทอง)+คู่ธาตุ(น้ำ) ตามตำรา weak มาตรฐาน · แต่ซินแสอ่านเป็น "เกือบสมดุล + โชคลาภแข็งแรง" → ให้ leverage 財(ไฟ)/食傷(ไม้) ไปหาเงินโดยตรง (ดวงเกือบสมดุลรับ 財 ได้) จึงเลือกธาตุต่างชุด
→ band/useful-god ป้อนเกือบทุกข้อ (อาชีพ/สี/ทิศ/เทพ) ทำให้ผลต่างเป็นลูกโซ่ — **นี่คือจุดที่ต้องตัดสินใจก่อน (เหมือนหลักฐาน [[strength-1988-divergence]] = engine กดอ่อนเกิน)**
