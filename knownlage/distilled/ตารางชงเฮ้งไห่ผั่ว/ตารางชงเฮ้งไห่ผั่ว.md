ตารางผั่ว(ราศีบนผั่วราศีล่าง)

| ราศีบน | ราศีล่าง | ความหมาย |
| --- | --- | --- |
| 甲 | 午 | การศึกษา การลงทุนทำให้เกิดความเสียหาย ลงทุนแล้วเกิดความเสียหายไม่เป็นไปตามคาด ช่วยเหลือหรือให้การสนับสนุนใครแล้วตัวเองเสียหาย |
| 乙 | 巳 | ความลุ่มหลงเที่ยวเตร่ทำให้เกิดความเสียหาย การแสดงออก การศึกษา ลงทุนที่มุ่งเน้นไปในทางที่ลุ่มหลงมัวเมา ทุ่มเทให้กับการเที่ยวเตร่มากเกินไปจนทำให้เกิดความเสียหาย |
| 丙 | 辰 | การใช้จ่าย ทุ่มเทให้กับการซื้อตำแหน่งเกินไป การที่ต้องใช้จ่ายหรือลงทุนไปในการซื้อตำแหน่ง หรือ ซื้อเพื่อศักดิ์ศรี หรือ เพื่อการศีกษาที่ต้องทุ่มเทมากกว่าปกติ |
| 丁 | 卯 | ผู้ใหญ่ช่วยเหลือเพื่อหวังผลประโยชน์จากเรา ผู้ที่สนับสนุน/ผู้ใหญ่ที่จะมาช่วยเหลือกลับไม่มีกำลัง หรือ มีแต่อยู่ห่างไกล และ มาช่วยเหลือเพื่อหวังผลประโยชน์ทำให้เสียหาย |
| 戊 | 寅 | ตำแหน่งที่ต้องแบกภาระ ลำบากก่อนดีทีหลัง หรือ ต้องตรากตรำลำบากก่อนแล้วค่อยสบายที่หลัง หรือ สำเร็จได้ดีในภายหลัง |
| 己 | 丑 | สูญเสียทางการเงินตลอดเวลา เก็บเงินไม่อยู่ |
| 己 | 亥 | ไม่สามารถเก็บสะสมเงินทองเป็นกอบเป็นกำ ลาภผลเงินทองที่เพียรเก็บสะสมเท่าไหร่ก็ไม่สามารถที่จะเก็บได้เป็นกอบเป็นกำ เนื่องจากลาภผลเสียหาย |
| 庚 | 子 | ช่วยเหลือผู้อื่นแล้วไม่เป็นผลดีกับตัวเอง จมทุน การแสดงออก หรือ ให้ความช่วยเหลือผู้อื่นแล้วไม่เกิดผลดีกับตัวเอง ปิดทองหลังพระ ลงทุนที่ทำให้เกิดความเสียหาย เสียเปรียบ จมทุน หรือ ขาดทุน |
| 庚 | 戌 | บุคคลที่ช่วยเหลือ/สนับสนุน เราทำให้เกิดความเดือดร้อน เสียหาย |
| 辛 | 酉 | การแก่งแย่งชิงดีชิงเด่น ไม่ยอมกัน ถ้าเป็นคู่ครองจะวางอำนาจ เอาเปรียบ ถ้าเป็นหุ้นส่วน ชอบทำอะไรข้ามหน้าข้ามตา |
| 壬 | 申 | กว่าจะมีผู้ให้ความช่วยเหลือจะต้องดิ้นรนต่อสู้ด้วยความยากลำบาก สุดท้ายก็จะได้พบกับผู้ที่จะให้ความช่วยเหลือจนได้ดี |
| 癸 | 未 | ภาระเกี่ยวข้องกับการเงิน หนี้สินมาก เสียหายทางการเงิน |
