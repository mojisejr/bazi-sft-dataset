1.1 ทายนิสัยตามดิถีแข็ง-ดิถีอ่อนแอ
อ้างอิง Step 3

| ดิถี | แข็ง-อ่อน | ความหมาย |
| --- | --- | --- |
| 甲 | แข็งแรงมากเกินไป | คนมั่นใจในตัวเองมาก แต่บางครั้งก็แข็งกระด้างและไม่ยอมคน ดื้อ ไม่ค่อยขยัน ชอบสบาย ไม่ค่อยยอมเปลี่ยนแปลง คิดเองทำเอง ไม่ค่อยมีเหตุผล และชอบเก็บความรู้สึกไว้คนเดียว |
| 甲 | แข็งแรง/สมดุล | มีเมตตา รักการทำบุญ ชอบช่วยเหลือผู้อื่น มุ่งมั่น ขยัน และใฝ่รู้ มีศักดิ์ศรี รักการพัฒนาและเรียนรู้ไม่สิ้นสุด มีความอดทน ยอมคน รักความสงบ ไม่ชอบมีเรื่องกับใคร เปิดเผย ชัดเจน คิดกว้าง มองไกล มีความพยายาม และรักครอบครัว |
| 甲 | อ่อนแอ | คนใจอ่อน ขี้สงสาร จนบางครั้งคนอื่นเอาเปรียบได้ง่าย ตัดสินใจเร็วเกินไป ไม่รอบคอบ รักสบาย ขี้น้อยใจ และไม่ค่อยมั่นใจในตัวเอง โกรธง่าย |
| 乙 | แข็งแรงมากเกินไป | ชอบแสวงหาประโยชน์ให้ตัวเอง ชอบแข่งขันและอยากชนะอยู่เสมอ มีไหวพริบดี แก้ปัญหาเฉพาะหน้าเก่ง ชอบเข้าสังคม อยากให้คนชื่นชม ไม่ชอบแพ้ใคร และมักมองผลประโยชน์ของตัวเองก่อน |
| 乙 | แข็งแรง/สมดุล | คนอ่อนโยน ใจดี ชอบศิลปะและความสวยงาม มีเสน่ห์ น่ารัก เข้าใจธรรมชาติ และปรับตัวเก่ง พูดจาไพเราะ มีไอเดียดี คิดไว แก้ปัญหาเก่ง เก่งเรื่องศิลปะและการแสดงออก แต่งตัวเก่ง ดูดีมีสไตล์ |
| 乙 | อ่อนแอ | คนไม่ค่อยมั่นใจในตัวเอง มักมองหาคนที่พึ่งพาได้ จิตใจอ่อนไหว ขี้ตกใจ และขี้น้อยใจ คิดเล็กคิดน้อย ไม่ค่อยวางแผนอนาคต ชอบทำอะไรช้า ๆ |
| 丙 | แข็งแรงมากเกินไป | มั่นใจในตัวเองสูง ไม่ชอบแพ้ อารมณ์ร้อน มักทำตามอารมณ์ ไม่ยอมฟังคนอื่น มองว่าตัวเองสำคัญกว่าใคร ๆ อยากเป็นจุดเด่น ไม่ชอบให้ใครมาขัด ไม่ค่อยเห็นใจคนอื่น สนใจภาพลักษณ์ของตัวเองมาก คนรอบข้างอาจรู้สึกกลัวหรืออึดอัด |
| 丙 | แข็งแรง/สมดุล | เป็นคนมีพลัง ชอบทำอะไรเต็มที่ สดใส กระตือรือร้น มั่นใจ ไม่ยอมแพ้ง่าย ชอบทำอะไรซ้ำ ๆ ตามความเคยชิน รักเพื่อน มีความรับผิดชอบ สุภาพ มีมารยาท รักความโดดเด่น ชอบตามกระแส มีศักดิ์ศรี ชอบสอน ชอบแบ่งปันความรู้ คิดกว้าง แต่มักห่วงภาพลักษณ์ โกรธง่ายแต่หายไว |
| 丙 | อ่อนแอ | ม่ค่อยมั่นใจในตัวเอง ขี้อิจฉา ไม่กล้าเปิดใจ ไม่ค่อยช่วยเหลือคนอื่น ไม่แน่นอน ทำให้คบกับคนอื่นยาก ไม่ชอบลองสิ่งใหม่ ไม่ชอบเสี่ยง รักตัวเอง คิดถึงตัวเองก่อน ไม่สนใจภาพลักษณ์ มักมีแนวทางของตัวเอง คนรอบข้างอาจมองข้าม เบื่อง่าย และชอบเลิกทำกลางคัน |
| 丁 | แข็งแรงมากเกินไป | หงุดหงิดง่าย โกรธแรง พูดหรือทำอะไรอาจทำให้คนอื่นเสียใจ แต่หายเร็ว ไม่คิดมากนาน ตัดสินใจเร็ว ชอบความเด่น มีพลัง เหมือนลุกเป็นไฟ ทำอะไรเร็วแรงจนบางคนรู้สึกกลัว เป็นคนคิดมาก ชอบระแวง |
| 丁 | แข็งแรง/สมดุล | อ่อนโยน สุภาพ กตัญญู รอบคอบ ชอบเรียนรู้ สนใจปรัชญาและการคิดลึกซึ้ง เก่งหลายด้าน เสียสละเพื่อคนอื่น ชอบเป็นแรงบันดาลใจให้คนรอบข้าง มีความรัก เข้าใจสถานการณ์รอบตัวเก่ง มองเห็นโอกาสและแนวทางได้ดี แต่บางครั้งมัวแต่ช่วยคนอื่นจนลืมดูแลตัวเอง |
| 丁 | อ่อนแอ | อารมณ์เปลี่ยนบ่อย ไม่มั่นคง ขาดพลังและความสดใส กลัวผิดหวัง มักเก็บฝังใจจากอดีต ขี้หนาว ต้องการความรักและกำลังใจ ขาดแรงผลักดันในการทำสิ่งต่าง ๆ มักคิดมาก ระวังตัวเกินไป และลืมที่จะกระตุ้นตัวเองให้เริ่มลงมือทำ |
| 戊 | แข็งแรงมากเกินไป | หัวแข็ง ดื้อ ไม่ยอมฟังใคร คิดแต่แบบของตัวเอง ไม่ยืดหยุ่น เชื่อมั่นในตัวเองจนเกินไป อารมณ์แรง นิ่งมากจนดูขี้เกียจ ไม่ค่อยไวต่อความรู้สึก จนบางครั้งต้องเรียนรู้จากความผิดพลาด |
| 戊 | แข็งแรง/สมดุล | เป็นคนจงรักภักดี ซื่อสัตย์ รอบคอบ น่าเชื่อถือ รักษาคำพูด ใจกว้าง พึ่งพาได้ ไม่ชอบเล่ห์เหลี่ยม เก็บความลับเก่ง สุภาพ เรียบง่าย พอใจกับสิ่งที่ตัวเองมี ชอบเก็บสะสม |
| 戊 | อ่อนแอ | ภายนอกดูเข้มแข็ง แต่ข้างในอ่อนไหว คิดมาก คิดวน ไม่มั่นใจในตัวเอง ช่วยคนอื่นจนลำบากตัวเอง บางครั้งเฉยชาจนดูไม่มีความรู้สึก ไม่รักษาคำพูด ถูกคนเอาเปรียบบ่อย ไม่มีเป้าหมายชัดเจน |
| 己 | แข็งแรงมากเกินไป | ชอบควบคุม ไม่ค่อยยอมปรับตัว ยึดมั่นในความคิดของตัวเองมากเกินไป ขาดสามัญสำนึก ไม่ยอมรับการเปลี่ยนแปลง ชอบแย่งหรือแข่งขัน รู้สึกว่าตัวเองไม่พอ ไม่เปิดใจฟังใคร |
| 己 | แข็งแรง/สมดุล | ป็นคนขยัน ทำหลายอย่างได้พร้อมกัน มีความคิดสร้างสรรค์ เข้าใจผู้อื่น ปรับตัวเก่ง ใจดี รู้จักแบ่งปัน ใช้ทรัพยากรได้ดี เข้าใจทั้งทางโลกและทางธรรม สงบ นิ่ง เป็นมิตรกับคนรอบข้าง |
| 己 | อ่อนแอ | ไม่ค่อยกล้าตัดสินใจ รักความสบาย ต้องการให้คนเอาใจใส่ คิดมาก ขี้สงสัย ไม่ค่อยรับผิดชอบ ตัดสินใจช้า ไม่ทันโอกาส ไม่มีระเบียบในชีวิต |
| 庚 | แข็งแรงมากเกินไป | เป็นคนใจร้อน อยากได้อะไรก็ต้องได้ ไม่ชอบรอ ดื้อและแข็งแรง ไม่กลัวใคร ชอบสั่งการ อารมณ์มากกว่าเหตุผล บางครั้งก็แสดงออกรุนแรง ไม่ยอมเสียเปรียบ และมักเปรียบเทียบกับคนอื่น |
| 庚 | แข็งแรง/สมดุล | เป็นคนรักความยุติธรรม มีความรับผิดชอบ ชัดเจน แข็งแกร่ง อดทนเก่ง มีแผนการ ชอบความท้าทาย กล้าสู้ กล้าเสี่ยง เปิดเผย และไม่ยอมแพ้ต่ออุปสรรคจนกว่าจะถึงเป้าหมาย |
| 庚 | อ่อนแอ | ป็นคนไม่ยืดหยุ่น ขาดความรอบคอบ ไม่เด็ดขาด คิดมากเกินไป ไม่เป็นระเบียบ ไม่มีหลักการ ไม่ค่อยสู้กับปัญหา และมักยอมแพ้ง่าย |
| 辛 | แข็งแรงมากเกินไป | ชอบความสวยงาม ทำตัวให้โดดเด่น ชอบเป็นที่สนใจ ต้องการคำชม และมักแทรกแซงเรื่องของคนอื่น บางครั้งอารมณ์ขึ้นง่าย และอาจสร้างภาพลักษณ์ไม่ดีโดยไม่ตั้งใจ |
| 辛 | แข็งแรง/สมดุล | ให้ความสำคัญกับภาพลักษณ์ ชอบแต่งตัวดี มีรสนิยม พูดจาดี ฉลาด มีไหวพริบ เป็นมิตรภายนอกแต่จริงใจ รับฟังเหตุผล วางแผนเก่ง รักศิลปะ เทคโนโลยี และชอบเป็นจุดสนใจ ถ้าไม่ได้รับความสนใจ อาจสร้างสถานการณ์ให้ตัวเองโดดเด่นขึ้นมาได้ |
| 辛 | อ่อนแอ | เป็นคนตื่นตกใจง่าย กังวลบ่อย ขาดความมั่นใจ หลงใหลวัตถุและความสนุกสนาน ฟังคนง่าย เชื่อคนง่าย และมักตามใจตัวเอง |
| 壬 | แข็งแรงมากเกินไป | เป็นคนใช้อารมณ์นำ ควบคุมยาก อารมณ์รุนแรงแต่ลึกซึ้ง ใจเด็ด ทะเยอทะยาน ชอบความสมบูรณ์แบบ มีแผนเยอะ ชอบเสี่ยงและไม่ชอบทำตามกฎ มีสองบุคลิก เดาใจยาก มักแหกกรอบ และอารมณ์ทางเพศค่อนข้างแรง |
| 壬 | แข็งแรง/สมดุล | ปรับตัวเก่ง อยู่กับใครก็ได้ มีพลังและฉลาดลึก ชอบแบ่งปันและประยุกต์ความรู้ รักอิสระ ชอบผจญภัย เข้าสังคมเก่ง ชอบเดินทาง คิดลึก รู้สึกไว ชอบเสี่ยง ตั้งใจจริง และไม่ชอบอยู่เฉยหรือตามคนอื่น อารมณ์ทางเพศสูง |
| 壬 | อ่อนแอ | เป็นคนขี้กังวล ไม่มั่นใจ โลเล ขี้เหงา ใจไม่มั่นคง รู้สึกตัวเองไร้จุดยืน คิดเล็กคิดน้อย ใจแคบ และอ่อนไหวง่าย |
| 癸 | แข็งแรงมากเกินไป | เป็นคนลึกลับ อารมณ์ขึ้น ๆ ลง ๆ ใจร้อน ทำหลายอย่างพร้อมกัน มักทำเฉพาะสิ่งที่ชอบหรือหลงใหล ไม่ชอบความเป๊ะ อ่านใจยาก คลุมเครือ สนใจเรื่องยาก ๆ ชอบค้นคว้า และไม่อยู่นิ่ง |
| 癸 | แข็งแรง/สมดุล | เป็นคนสงบ เยือกเย็น ชอบช่วยเหลือ มีความคิดสร้างสรรค์ ชอบสิ่งลึกลับและไม่เหมือนใคร ฉลาด เรียนรู้เร็ว มีลางสังหรณ์ รักอิสระ เข้าใจสิ่งต่าง ๆ ได้ลึกซึ้ง แต่ไม่ชอบแสดงออก อ่านใจยาก โรแมนติก และไม่ชอบหยุดนิ่ง |
| 癸 | อ่อนแอ | ไม่ค่อยกล้าแสดงออก อ่อนไหว ชอบเก็บความรู้สึกไว้ในใจ คิดเล็กคิดน้อย ไม่ชอบเข้าสังคม มักถูกมองข้าม ทำอะไรไม่สม่ำเสมอ และไม่ค่อยอดทน |

1.2 ทายตามคู่ราศีบนหลักวัน กับ ราศล่างหลักวัน
อ้างอิงตาราง หลักปี หลักเดือน หลักวัน หลักยาม

| หลักวัน | ความหมาย |
| --- | --- |
| 甲 | เป็นคนใจดี มีเมตตา รักการทำบุญ ชอบช่วยเหลือผู้อื่น มุ่งมั่น ขยัน และใฝ่รู้ มีศักดิ์ศรี รักการพัฒนาและเรียนรู้ไม่สิ้นสุด มีความอดทน ยอมคน รักความสงบ ไม่ชอบมีเรื่องกับใคร เปิดเผย ชัดเจน คิดกว้าง มองไกล มีความพยายาม และรักครอบครัว |
| 子 | เคลื่อนไหวไว ไหวพริบดี มักระวังตัวและไม่ประมาท ชอบสังเกตและจับจังหวะก่อนลงมือ ชินกับการทำงานหรือใช้ชีวิตในช่วงกลางคืน รู้จักเลือกอยู่ในที่ที่ปลอดภัย และมีนิสัยชอบสะสมหรือเตรียมสำรองไว้ล่วงหน้าเสมอ |
| หมกยก | มีความสามารถ มีเสน่ห์น่าค้นหา แต่กลับไม่ค่อยมีใครมองเห็นคุณค่า และหาคนจริงใจได้ยาก หากคุณขยันและตั้งใจในการเรียนรู้หรือทำงาน จะทำให้มีชื่อเสียงและเป็นที่ยอมรับ แม้บางช่วงจะรู้สึกท้อแท้ เบื่อหน่าย หรือไม่มีกำลังใจ แต่หากคุณผลักดันตัวเองอย่างจริงจัง ความสำเร็จจะเกิดขึ้นแน่นอน |
