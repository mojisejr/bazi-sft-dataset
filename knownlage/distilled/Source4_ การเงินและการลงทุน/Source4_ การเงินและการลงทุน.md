Source 4: การเงินและการลงทุน (Wealth & Investment)
Objective: ใช้สำหรับทำนายศักยภาพการเงิน, แหล่งที่มาของรายได้, พฤติกรรมการใช้จ่าย/ลงทุน และจังหวะเวลา
1. Wealth Potential Analysis (วิเคราะห์ศักยภาพการเงิน)
เงื่อนไข: ตรวจสอบ "ความแข็งแรงของหลักวันราศีบน" (ดิถี) เทียบกับรูปดวง

| ความแข็งแรงของหลักวันราศีบน | ผลคำทำนาย |
| --- | --- |
| แข็งแรงเกินไป | มีพละกำลังในการหาโชคลาภ แต่มักมีการแข่งขันสูง ไม่ได้โชคลาภเท่าที่คิด |
| แข็งแรง / สมดุล | มีพละกำลังในการหาโชคลาภได้ดี หารายได้ได้ง่าย |
| อ่อนแอ | ไม่มีพละกำลังในการหาโชคลาภ หารายได้ได้ยาก แต่ยังพอหาเลี้ยงชีพ |
| อ่อนแอเกินไป | ไม่มีพละกำลังในการหาโชคลาภ ทำมาหากินลำบาก |

3. การวิเคราะห์ที่มาและความมั่นคงของทรัพย์
ตรรกะการทำงาน:
ตรวจสอบว่าในดวงมี "คลังทรัพย์" (จากตารางข้อ 2) หรือไม่
ถ้ามี ให้ดู "ตำแหน่งหลัก" เพื่อทำนายที่มา
ตรวจสอบ "ตัวกระทบ" (ชง หรือ ตัวทำลาย) เพื่อทำนายความมั่นคง
3.1 ทำนายแหล่งที่มาของทรัพย์ (ตามตำแหน่งคลัง)

| ตำแหน่งที่พบคลังทรัพย์ | คำทำนายแหล่งที่มา |
| --- | --- |
| หลักปี | ทรัพย์จากของเก่า, มรดก, ปู่ย่าตายาย หรือจากฐานลูกค้า |
| หลักเดือน | ทรัพย์จากพ่อแม่, ครอบครัว, ธุรกิจการงาน หรือที่ทำงาน |
| หลักวัน | ทรัพย์จากตนเอง, คู่ครอง, พี่น้อง หรือหุ้นส่วน |
| หลักยาม | ทรัพย์จากลูกหลาน, บริวาร หรือทรัพย์ที่จะงอกเงยค่าในยามชรา |

3.2 ทำนายความมั่นคงและการรั่วไหล (ตามตัวกระทบ)
กรณีคลังถูกชง (ปะทะ): (เช่น มี 辰 เจอ 戌)
ผลลัพธ์: คลังเปิดออก นำทรัพย์มาใช้ได้ (รวยเร็ว) แต่ถ้าชงเยอะไป จะเก็บเงินไม่อยู่
กรณีคลังถูกทำลาย (เจอตัวทำลาย): (เช่น ดิถี 甲 เจอ 丙 หรือ 辛)
ผลลัพธ์: เก็บเงินไม่อยู่ มีรูรั่วทางการเงิน ระวังการยักยอก ห้ามให้คนที่มีธาตุนี้ดูแลการเงิน
รายละเอียดสาเหตุ (ดูตำแหน่งตัวทำลาย):
อยู่หลักปี: เสียเงินเพราะลูกค้า สังคมภายนอก ผู้ใหญ่ หรือลำบากวัยเด็ก
อยู่หลักเดือน: เสียเงินเพราะพ่อแม่ ครอบครัว ธุรกิจ หรือลำบากวัยทำงาน
อยู่หลักยาม: เสียเงินเพราะลูกหลาน บริวาร หรือลำบากยามแก่เฒ่า
3.3 เกณฑ์พิเศษการทำนายขุมทรัพย์ (Special Interactions)
ดิถี 甲 และ 乙 (คลัง 辰):
เจอ 子 (หนู) ร่วมด้วย: หาลาภผลไม่เหน็ดเหนื่อย ไม่ล่าช้า มีคนช่วยเหลือ
เจอ 辰/未/丑/戌 (ดินอื่นๆ): เสียหายเรื่องเงินเก็บ เก็บเงินไม่อยู่
ดิถี 丙 และ 丁 (คลัง 丑):
เจอ 酉 (ไก่) ร่วมด้วย: มีคนช่วยเก็บสะสม ต่อยอดทรัพย์สิน
เจอ 辰/未/戌: ลงทุนผิดพลาด เสียหายเรื่องเงินเก็บ
ดิถี 戊 และ 己 (คลัง 辰):
เจอ 申 (ลิง) หรือ 子 (หนู) ร่วมด้วย: หาทรัพย์ได้มากมาย / พัฒนาด้วยปัญญา
เจอ 辰/未/丑/戌: เสียหายเรื่องเงินเก็บ
ดิถี 庚 และ 辛 (คลัง 未):
เจอ 卯 (เถาะ): (庚) มีโชคลาภต่อเนื่อง / (辛) ระวังลาภผลเสียหาย
เจอ 午 (มะเมีย): (辛) รายจ่ายมากมาย สูญเสียเงินเก็บ
ดิถี 壬 และ 癸 (คลัง 戌):
เจอ 午 (มะเมีย): (壬) สะสมทรัพย์ต่อเนื่อง / (癸) เสียทรัพย์สินเงินเก็บ
เจอ 卯 (เถาะ): (壬) เน้นเก็บไม่ลงทุน / (癸) ลงทุนเพื่อเพิ่มพูน

4.1 Logic การประเมินกำลังธาตุถ่ายเท (Output Strength Calculation)
เกณฑ์แข็งแรง (Strong Output):
มีจำนวนธาตุถ่ายเท ตั้งแต่ 2 ตัวขึ้นไป ในดวง
หรือ อยู่ในสถานะ 12 เชี่ยงแซ ที่ดี (เชี่ยงแซ, กวงตั่ว, ลิ่มกัว, ตี้อ๋วง, หมอ, ทอ, เอี้ยง)
ผลทำนาย: "มีผู้สนับสนุนให้เกิดโชคลาภ"
เกณฑ์อ่อนแอ (Weak Output):
ถูก เฮ้ง (Punishment) หรือ ชง (Clash) โดยราศีที่อยู่ติดกัน
ถูก ผั่ว (Destruction) ไม่ว่าจะอยู่ตำแหน่งใด
ผลทำนาย: "ไม่มีผู้สนับสนุนให้เกิดโชคลาภ"

| สถานะ (12 เชี่ยงแซ) | พฤติกรรมการใช้จ่าย | พฤติกรรมการลงทุน |
| --- | --- | --- |
| 1. เชี่ยงแซ (เกิด) | ใช้จ่ายมีเหตุผล เพื่อความเจริญรุ่งเรือง หรือพัฒนาตนเอง | ลงทุนกับสิ่งใหม่, Start-up, เพื่อการเติบโต |
| 2. หมกยก (อาบน้ำ) | ใช้จ่ายลุ่มหลง มัวเมา, ของสวยงาม, อบายมุข | ลงทุนธุรกิจสีเทา, ความงาม, แฟชั่น, ของมึนเมา |
| 3. กวงตั่ว (สายรัดเอว) | ใช้จ่ายเชิงวิชาการ, การเรียนรู้, เรื่องเฉพาะทาง | ลงทุนในความรู้, ค้นคว้าข้อมูล, สินค้าเฉพาะทาง |
| 4. ลิ่มกัว (ขุนนาง) | ใช้จ่ายเพื่ออำนาจ, หน่วยงานรัฐ, การเมือง | ลงทุนภาครัฐ, สัมปทาน, กิจการมั่นคงมีเกียรติ |
| 5. ตี้อ๋วง (ราชา) | ใช้จ่ายมีศักดิ์ศรี, หน้าใหญ่ใจโต, แสดงอำนาจ | ลงทุนใช้อำนาจต่อรอง, เก็งกำไร, ลงทุนตามใจ |
| 6. ซวย (เสื่อมถอย) | ใช้จ่ายเกี่ยวกับของเก่า, ของโบราณ, ความล่าช้า | ลงทุนคืนทุนช้า, ของมือสอง, อสังหาฯ เก่า |
| 7. แป่ (เจ็บป่วย) | ใช้จ่ายสุรุ่ยสุร่าย, ของทันสมัย, ค่ารักษาพยาบาล | ลงทุนเทคโนโลยี, การเดินทาง, ลงทุนจำนวนมาก |
| 8. ซี่ (ตาย) | ขี้เหนียว, ไม่ค่อยใช้จ่าย, เรื่องความตาย/ความเศร้า | ไม่ลงทุน (กลัวความเสี่ยง), ลงทุนแล้วจมทุน |
| 9. หมอ (หลุมศพ) | เก็บเงินเก่ง, ใช้จ่ายกับอสังหาฯ/การสะสม | ลงทุนอสังหาฯ, ที่ดิน, ใช้ทุนเดิมมาต่อยอด |
| 10. เจ๊าะ (สูญสิ้น) | ใช้จ่ายผิดๆ, เสียเงินโดยใช่เหตุ, เรื่องความเจ็บปวด | ลงทุนแล้วเสียหาย, เงินทุนสูญหาย |
| 11. ทอ (ปฏิสนธิ) | จ่ายทีละน้อย (เบี้ยหัวแตก), จ่ายบ่อย, เรื่องบุตร | ลงทุนค่อยเป็นค่อยไป, ลงทุนระยะยาว |
| 12. เอี้ยง (เลี้ยงดู) | จ่ายของจุกจิก, ของสะสมชิ้นเล็ก, การดูแลเลี้ยงดู | ลงทุนแบบไม่ตั้งใจ, ธุรกิจบริการ/ดูแลคน |

5. การปรับแก้ดวงการเงิน (Wealth Solution)
คำสั่ง: เลือกธาตุที่เหมาะสม เพื่อเสริมดวงตามความแข็ง/อ่อน

| ดิถี (หลักวัน) | กรณี: ดวงแข็ง (แข็งแรง/เกินไป) | กรณี: ดวงอ่อน (อ่อนแอ/เกินไป) |
| --- | --- | --- |
| ไม้ (甲/乙) | ใช้ ธาตุไฟ (เพิ่มประสิทธิภาพ) | ใช้ ธาตุน้ำ, ธาตุไม้ (เสริมกำลัง) |
| ไฟ (丙/丁) | ใช้ ธาตุดิน, ธาตุทอง (เพิ่มประสิทธิภาพ) | ใช้ ธาตุไม้, ธาตุไฟ (เสริมกำลัง) |
| ดิน (戊/己) | ใช้ ธาตุทอง, ธาตุน้ำ (เพิ่มประสิทธิภาพ) | ใช้ ธาตุไฟ, ธาตุดิน (เสริมกำลัง) |
| ทอง (庚/辛) | ใช้ ธาตุน้ำ, ธาตุไม้ (เพิ่มประสิทธิภาพ) | ใช้ ธาตุดิน, ธาตุทอง (เสริมกำลัง) |
| น้ำ (壬/癸) | ใช้ ธาตุไม้, ธาตุไฟ (เพิ่มประสิทธิภาพ) | ใช้ ธาตุทอง, ธาตุน้ำ (เสริมกำลัง) |

ความหมายเชิงธุรกิจของ 5 ธาตุ (สำหรับให้คำแนะนำ)
ธาตุดิน: อสังหาริมทรัพย์, วัสดุก่อสร้าง, ความน่าเชื่อถือ, ความมั่นคง, ปศุสัตว์, การเกษตร
ธาตุทอง: เทคโนโลยี, เครื่องจักร, ยานยนต์, ความยุติธรรม, ความเด็ดขาด, เครื่องประดับ, โลหะ
ธาตุน้ำ: การเงิน, การขนส่ง, อาหารเครื่องดื่ม, ธุรกิจกลางคืน, การบริการ, สติปัญญา
ธาตุไม้: สิ่งทอ, เสื้อผ้า, สมุนไพร, สื่อสิ่งพิมพ์, การศึกษา, ความเมตตา, การขนส่ง
ธาตุไฟ: พลังงาน, แสงสว่าง, โซเชียลมีเดีย, การแสดง, ความงาม, ธุรกิจบริการ, อาหารปรุงสุก
6. จังหวะเวลาแห่งความรวย (Timing Prediction)
ตรรกะการทำงาน: วิเคราะห์ "ปีจร" และ "วัยจร" ว่าเหมาะสมกับการลงทุนหรือไม่
ขั้นตอนที่ 1: ตรวจสอบความต้องการของดวง
ถ้าดวงอ่อน: ต้องรอปี/วัยจรที่เป็น "คู่ธาตุ" หรือ "ธาตุส่งเสริม" (เพื่อให้มีแรงหาเงิน)
ถ้าดวงแข็ง: ต้องรอปี/วัยจรที่เป็น "ธาตุถ่ายเท" หรือ "ธาตุลาภ" (เพื่อให้มีช่องทางระบายออกเป็นเงิน)
ขั้นตอนที่ 2: ตรวจสอบคุณภาพธาตุลาภ
ตรวจสอบว่า "ธาตุลาภ" ในปีนั้น/วัยนั้น อยู่ในสถานะ (12 เชี่ยงแซ) ที่ดีหรือไม่?
เงื่อนไข: หากเป็น เชี่ยงแซ (1), ลิ่มกัว (4), หรือ ตี้อ๋วง (5)
ผลลัพธ์: "วัยจร/ปีจรนี้ เหมาะแก่การลงทุน ริเริ่มก่อเกิดลาภผล แล้วดี"
