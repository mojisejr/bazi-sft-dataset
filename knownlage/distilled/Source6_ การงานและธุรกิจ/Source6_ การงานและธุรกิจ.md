📂 Source 6: การงานและธุรกิจ (Career & Business)
Objective: วิเคราะห์อาชีพที่เหมาะสม, สถานะการงาน, การเปลี่ยนงาน, ความก้าวหน้า, ทำเลที่ตั้ง, การลงทุน และกลุ่มลูกค้า
1. Career Suitability (1.1 อาชีพและธุรกิจที่เหมาะสม)
Logic: เลือกอาชีพตาม "ความแข็งแรงของดิถี" และ "ธาตุ"
1.1.1 ตรรกะการเลือกธาตุ (Element Selection Logic)

| ความแข็งแรงของดิถี | ธาตุอาชีพที่แนะนำ |
| --- | --- |
| แข็งแรงเกินไป | อาชีพที่เป็น ธาตุถ่ายเท |
| แข็งแรง หรือ สมดุล | อาชีพที่เป็น ธาตุถ่ายเท และ ธาตุลาภ |
| อ่อนแอ หรือ อ่อนแอเกินไป | อาชีพที่เป็น คู่ธาตุ และ ธาตุส่งเสริม |
| เงื่อนไขเพิ่มเติม | ไม่ควรทำธุรกิจถ้าไม่มีความพร้อมในเชิงดวง และวัยจรที่ดีเกื้อหนุน |

1.1.2 รายละเอียดอาชีพตามธาตุ (Career List by Element)
ข้อมูลดิบสำหรับ AI ใช้แนะนำอาชีพ:
ธาตุดิน:
วัสดุก่อสร้าง (อิฐ หิน ปูน ทราย กระจก ปูนซีเมนต์ กระเบื้อง)
อสังหาริมทรัพย์ (ที่ดิน บ้าน คอนโด โกดัง อาคาร รับเหมาก่อสร้าง พัฒนาอสังหาฯ)
การเกษตร/ปศุสัตว์ (ชาวนา ชาวไร่ ปุ๋ย อาหารสัตว์ สัตว์เลี้ยง ช้าง ม้า วัว ควาย)
อื่นๆ (เครื่องปั้นดินเผา แก้ว หลุมฝังศพ แร่ธาตุ หนังสัตว์ กระดูก)
ธาตุทอง:
โลหะทุกชนิด (เหล็ก อลูมิเนียม ทองแดง สแตนเลส ทองคำ เงิน เพชร นาฬิกา มีด)
เครื่องจักร/เทคโนโลยี (รถยนต์ อะไหล่ เครื่องมือช่าง เครื่องใช้ไฟฟ้า คอมพิวเตอร์)
ราชการ/กฎหมาย (ทหาร ตำรวจ อัยการ ผู้พิพากษา ศาล กฎหมาย)
อื่นๆ (โรงรับจำนำ ดาราศาสตร์ ชกมวย ตัดผม)
ธาตุน้ำ:
การเงิน/การบริการ (ธนาคาร หุ้น บัญชี สินเชื่อ ประกัน นายหน้า โรงแรม สปา นวด)
อาหาร/เครื่องดื่ม (ร้านอาหาร กาแฟ เครื่องดื่มห้องเย็น น้ำแข็ง)
การขนส่ง/ท่องเที่ยว (ไกด์ มัคคุเทศก์ เดินเรือ ดำน้ำ ขนส่ง)
บันเทิง/กลางคืน (นักแสดง นักร้อง ผับบาร์)
อื่นๆ (ซักรีด ล้างรถ ร้านสะดวกซื้อ พนักงานเงินเดือน)
ธาตุไม้:
เกษตร/ธรรมชาติ (ต้นไม้ ดอกไม้ สมุนไพร ใบชา จัดสวน)
สิ่งทอ/กระดาษ (เสื้อผ้า ทอผ้า ผ้าม่าน กระดาษ หนังสือ สื่อสิ่งพิมพ์)
การศึกษา/ศาสนา (เครื่องเขียน อุปกรณ์การเรียน มูลนิธิ การกุศล)
อื่นๆ (เฟอร์นิเจอร์ไม้ ตกแต่งภายใน นำเข้าส่งออก อินเตอร์เน็ต ศิลปะ จิตรกร)
ธาตุไฟ:
พลังงาน/แสงสว่าง (ไฟฟ้า หลอดไฟ แบตเตอรี่ โซล่าเซลล์ ถ่านไฟ)
ความร้อน/แปรรูป (เชื่อม อ๊อก เครื่องอบ ร้านอาหารปรุงสุก)
ความงาม/ยา (โรงพยาบาล เภสัช เครื่องสำอาง เสริมสวย)
วิชาการ/ความเชื่อ (ครู อาจารย์ โค้ช โหราศาสตร์ หมอดู พระ)
อื่นๆ (แว่นตา กล้องถ่ายรูป ประทัด ระเบิด การตลาด ที่ปรึกษา)

3. Job Change & Application (1.3 - 1.4 การเปลี่ยนงาน/สมัครงาน)
Logic: วิเคราะห์ "โอกาสได้งานใหม่" หรือ "การเปลี่ยนแปลง" ปัจจัยที่ใช้:
ดิถี (ราศีบนวัน) เทียบกับ วัยจร/ปีจร
ฐานงาน (ราศีบนเดือน) เทียบกับ วัยจร/ปีจร Weight: ให้น้ำหนัก วัยจร 60% / ปีจร 40%

นำธาตุถ่ายเทไปเทียบกับ ราศีบนหลักเดือน (เทียบ 12 เชี่ยงแซ)

นำธาตุถ่ายเทไปเทียบกับ ราศีบนหลักปี (เทียบ 12 เชี่ยงแซ)
ดี = ทำต่างประเทศ/ไกลบ้าน ดี
เสีย = ทำต่างประเทศ/ไกลบ้าน ไม่ดี

6.2 ความหมายธุรกิจตาม 12 เชี่ยงแซ (Business Nature)
คำสั่ง: นำ "ธาตุลาภ" มาเทียบกับ "ราศีบนหลักเดือน (ฐานธุรกิจ)"
Logic เพิ่มเติม:
วิเคราะห์ "ธาตุโชคลาภของดิถี" เทียบกับ ฐานธุรกิจ (ราศีบนเดือน) -> ได้ผลลัพธ์ A
วิเคราะห์ "ธาตุโชคลาภของราศีบนหลักเดือน (ฐานธุรกิจ)" เทียบกับ ฐานธุรกิจ (ตัวมันเอง) -> ได้ผลลัพธ์ B
สรุปผล: ให้นำความหมายของ A และ B มา ผสมรวมกัน เพื่อทำนายลักษณะธุรกิจที่เหมาะสมที่สุด

| สถานะ (Qi Phase) | ความหมายลักษณะธุรกิจ |
| --- | --- |
| 1. เชี่ยงแซ | ธุรกิจเริ่มต้นใหม่, การพัฒนา, นวัตกรรม |
| 2. หมกยก | ธุรกิจบันเทิง, ความสวยงาม, การชำระล้าง, สีเทา |
| 3. กวงตั่ว | ธุรกิจวิชาการ, การสอน, โรงเรียน, ศาสนา |
| 4. ลิ่มกัว | ธุรกิจเกี่ยวกับรัฐ, ข้าราชการ, สัมปทาน |
| 5. ตี้อ๋วง | ธุรกิจใช้อำนาจต่อรอง, สินค้าหรูหรา, ระดับสูง |
| 6. ซวย | ธุรกิจของเก่า, รีไซเคิล, แก้เคราะห์ |
| 7. แป่ | ธุรกิจการเดินทาง, ขนส่ง, เทคโนโลยีล้ำสมัย, การรักษา |
| 8. ซี่ | ธุรกิจความเชื่อ, ความตาย, สมาธิ, ความเศร้า |
| 9. หมอ | ธุรกิจโกดัง, อสังหาฯ, การเก็บสะสม |
| 10. เจ๊าะ | ธุรกิจย่อยสลาย, ทำลายเชื้อ, แก้ปัญหาความแตกแยก |
| 11. ทอ | ธุรกิจแม่และเด็ก, การตั้งครรภ์, การจับคู่ |
| 12. เอี้ยง | ธุรกิจบริการ, ดูแลคนแก่/เด็ก, งานประคบประหงม |

7.2 ความหมายการลงทุน (Investment Meanings)
เชี่ยงแซ: ลงทุนสิ่งใหม่/Start-up
หมกยก: ลงทุนความงาม/บันเทิง
กวงตั่ว: ลงทุนความรู้/เฉพาะทาง
ลิ่มกัว: ลงทุนภาครัฐ/การเมือง
ตี้อ๋วง: ลงทุนเก็งกำไร/ใช้อำนาจ
ซวย: ลงทุนของเก่า/มือสอง (คืนทุนช้า)
แป่: ลงทุนเทคโนโลยี/ต่างถิ่น/Health Tech
ซี่: ไม่ควรลงทุน (หรือลงทุนเกี่ยวกับความตาย)
หมอ: ลงทุนอสังหาฯ/เก็บกินยาว
เจ๊าะ: ลงทุนเสี่ยงสูง (ระวังเสียหาย)
ทอ: ลงทุนระยะยาว/DCA
เอี้ยง: ลงทุนธุรกิจบริการ/ดูแล
8. Customer Analysis (กลุ่มลูกค้า)
Logic: วิเคราะห์จาก "หลักปี" (Year Pillar)
คำสั่ง: นำ "ราศีบนหลักปี" เทียบกับ "ราศีล่างหลักปี" ในระบบ 12 เชี่ยงแซ

| สถานะ (Qi Phase) | ลักษณะกลุ่มลูกค้า |
| --- | --- |
| 1. เชี่ยงแซ | ลูกค้ามีความสามารถในการพัฒนา, ชอบสิ่งใหม่ |
| 2. หมกยก | ลูกค้าที่มีปัญหาต้องการความช่วยเหลือ (หรือลูกค้าหน้าตาดี) |
| 3. กวงตั่ว | ลูกค้าวิชาการ, เจ้าหลักการ, มีเหตุผล |
| 4. ลิ่มกัว | ลูกค้าถืออำนาจ, ข้าราชการ, คนมีตำแหน่ง |
| 5. ตี้อ๋วง | ลูกค้าวางอำนาจ, เจ้ายศเจ้าอย่าง, ไฮโซ |
| 6. ซวย | ลูกค้าเก่า, ลูกค้าขี้บ่น/จู้จี้จุกจิก |
| 7. แป่ | ลูกค้าทางไกล, ลูกค้าทันสมัย (Trendsetter) |
| 8. ซี่ | ลูกค้าประจำ, ลูกค้าชอบของถูก |
| 9. หมอ | ลูกค้ามีมรดก, ลูกค้าชอบซื้อตุน/กักตุนสินค้า |
| 10. เจ๊าะ | ลูกค้าที่ทำให้เกิดความเสียหาย, ลูกค้าที่มีความลำบาก |
| 11. ทอ | ลูกค้าที่เพิ่งเริ่มสร้างตัว, ลูกค้าเรื่องมาก |
| 12. เอี้ยง | ลูกค้าที่ชอบการบริการ, ต้องคอยดูแลเอาใจใส่ |

หมายเหตุ: ความหมายอาจเปลี่ยนแปลงหากมีการ ภาคี, ชง, เฮ้ง, ผั่ว ในหลักปี
