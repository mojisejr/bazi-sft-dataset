2.2 List "ธาตุคู่ครองมีกำลัง" (Strong Spouse Element)
Logic: หากธาตุคู่ครองตรงกับ List นี้ ถือว่า "แข็งแรง/มีกำลัง" (คู่ส่งเสริมดี/หาคู่ง่าย)
ราศีบนคู่ครอง: 甲子, 甲寅, 乙戌, 乙卯, 丙未, 丙寅, 丁午, 丁戌, 戊巳, 戊未, 己酉, 己子, 庚辰, 庚午, 辛戌, 辛丑, 壬巳, 壬未, 癸酉, 癸亥, ฯลฯ (ตามตารางต้นฉบับ)

2.3 ตารางทำนาย: ความสัมพันธ์ตามกำลังธาตุคู่ครอง
Logic: ประเมินความแข็งแรงของ "ธาตุคู่ครอง" (ธาตุลาภของชาย / ธาตุสามีของหญิง) แล้วดูผลลัพธ์

| ความแข็งแรงของธาตุคู่ครอง | ผลคำทำนาย (ใช้ได้ทั้งชายและหญิง) |
| --- | --- |
| แข็งแรงเกินไป | คู่ไม่ค่อยสนใจในตัวเรา, คู่มีความเชื่อมั่นในตัวเองสูงเกินไป |
| แข็งแรง / มีกำลัง | หาคู่ได้ง่าย, มีคนให้เลือกชอบหลากหลาย, ความรักสดใส |
| อ่อนแอ / ไม่มีกำลัง | หาคู่ยาก, ไม่ค่อยมีใครเข้ามาให้ชอบ |
| อ่อนแอเกินไป | คู่มีนิสัยกล้าๆ กลัวๆ, ไม่ค่อยมีความมั่นใจในตัวเอง |

Special Rule: กรณีหาธาตุคู่ครองไม่เจอ
หากในดวงไม่มีทั้ง "ธาตุแท้" และ "ธาตุแฝง" ให้ใช้ "ราศีล่างหลักวัน (ฐานคู่)" มาเทียบกับ "ราศีบนหลักวัน (ดิถี)" ในตาราง 12 เชี่ยงแซแทน
ได้เชี่ยงแซดี (1,3,4,5,9,11,12) = ได้คู่ดี เกื้อกูลกัน
ได้เชี่ยงแซร้าย (2,6,7,8,10) = คู่มีปัญหา หรือไม่มีคู่
3. Relationship Quality (คุณภาพความรัก - 12 เชี่ยงแซ)
Logic: นำ "ราศีบนหลักวัน vs ราศีล่างหลักวัน" และ “ราศีบนหลักวัน vs ธาตุคู่ครอง” มาเทียบ 12 เชี่ยงแซ

| สถานะ (Qi Phase) | ความหมายความรัก |
| --- | --- |
| 1. เชี่ยงแซ | มีคู่แล้วเจริญรุ่งเรือง ก้าวหน้า ช่วยกันพัฒนา |
| 2. หมกยก | คู่มีเสน่ห์ หลงใหลกันและกัน (หรือเจ้าชู้) |
| 3. กวงตั่ว | คู่มีความรู้ ความสามารถ ใช้เหตุผล เข้าอกเข้าใจ |
| 4. ลิ่มกัว | คู่มียศศักดิ์ มีตำแหน่ง มีหน้าตาทางสังคม |
| 5. ตี้อ๋วง | คู่มีศักดิ์ศรี มีอำนาจบารมี (บางทีใช้อำนาจเกินขอบเขต) |
| 6. ซวย | คู่ล้าสมัย หัวโบราณ เรียบร้อย หรือขี้บ่น |
| 7. แป่ | คู่มาจากทางไกล/ต่างถิ่น ขยันขันแข็ง ทันสมัย |
| 8. ซี่ | ไม่มีคู่ หรือคู่ตายจาก หมดเยื่อใย |
| 9. หมอ | คู่มีสมบัติ ฐานะดีขึ้นหลังแต่ง ชอบอยู่บ้าน |
| 10. เจ๊าะ | ไม่มีคู่, อยู่ก่อนแต่ง, คบแล้วมีความเสียหายเกิดขึ้น |
| 11. ทอ | คู่น่ารัก น่าเอ็นดู ชอบให้ดูแลประคบประหงม |
| 12. เอี้ยง | คู่นิสัยเหมือนเด็ก อ่อนกว่าวัย ต้องเลี้ยงดูทะนุถนอม |

4. Conflict & Interaction (เฮ้ง ชง ผั่ว ภาคี)
4.1 การเฮ้ง (Punishment - ภัยเงียบ/อึดอัด)
ฐานคู่ (วัน) เฮ้ง ปี: คู่มีปัญหากับ ปู่/ย่า/ตา/ยาย/ลูกค้า/สังคม
ฐานคู่ (วัน) เฮ้ง เดือน: คู่มีปัญหากับ แม่/ครอบครัว/ธุรกิจครอบครัว
ฐานคู่ (วัน) เฮ้ง ยาม: คู่มีปัญหากับ ลูกหลาน/บริวาร
ฐานคู่ เฮ้ง เดือน+ยาม: มีคู่ยาก หรือ ไม่มีคู่
4.2 การชง (Clash - ปะทะ/เปลี่ยนแปลง)
ฐานคู่ (วัน) ชง ปี: คู่ปะทะกับ ปู่/ย่า/ลูกค้า/สังคม
ฐานคู่ (วัน) ชง เดือน: คู่ปะทะกับ แม่/ครอบครัว/ที่ทำงาน
ฐานคู่ (วัน) ชง ยาม: คู่ปะทะกับ ลูกหลาน/บริวาร
4.3 การผั่ว (Destruction - แตกหัก/รอยร้าว)
ราศีบนวัน ผั่ว ราศีล่างวัน: ชีวิตคู่ทะเลาะเบาะแว้งประจำ, ไม่มีคู่
ฐานคู่ (วัน) ผั่ว ปี: คู่ทะเลาะกับ ปู่/ย่า/ลูกค้า/สังคม
ฐานคู่ (วัน) ผั่ว เดือน: คู่ทะเลาะกับ พ่อ/เจ้านาย/ธุรกิจ
ฐานคู่ (วัน) ผั่ว วัน: ทะเลาะกับดิถี, เป็นหม้าย, อายุห่างกัน
ฐานคู่ (วัน) ผั่ว ยาม: คู่ทะเลาะกับ ลูกหลาน/บริวาร
4.4 การภาคี (Combination - การร่วมมือ)
Logic: ฐานคู่ (วัน) ไปฮะกับหลักไหน = คู่ร่วมมือกับคนกลุ่มนั้น
ฮะ ปี: ร่วมมือกับ ปู่/ย่า/ลูกค้า (ถ้าฮะเป็นธาตุดี=ดี, ฮะเป็นธาตุร้าย=เสีย)
ฮะ เดือน: ร่วมมือกับ แม่/ครอบครัว/ธุรกิจ
ฮะ ยาม: ร่วมมือกับ ลูกหลาน/บริวาร
5. Marriage Timing (แต่งงานเมื่อไหร่?)
5.1 เกณฑ์วัยจร/ปีจร (Timing Logic)
Logic: ดูว่าดิถีต้องการธาตุอะไร แล้วรอปี/วัยจรนั้นมา
ดิถีชาย แข็งแรงเกินไป: รอธาตุ ถ่ายเท (Output)
ดิถีชาย แข็ง/สมดุล: รอธาตุ ลาภ (Wealth)
ดิถีชาย อ่อน: รอธาตุ คู่ธาตุ หรือ ส่งเสริม
ดิถีหญิง แข็งแรงเกินไป: รอธาตุ ถ่ายเท (Output)
ดิถีหญิง แข็ง/สมดุล: รอธาตุ สามี (Power)
ดิถีหญิง อ่อน: รอธาตุ คู่ธาตุ หรือ ส่งเสริม
5.2 เกณฑ์คุณภาพ (Quality Check)
หากปี/วัยจรนั้น เป็น เชี่ยงแซ, กวงตั่ว, ลิ่มกัว, ตี้อ๋วง, หมอ, ทอ, เอี้ยง (เมื่อเทียบกับดิถี) = เพิ่มโอกาสมีคู่สูง
5.3 เกณฑ์พิเศษ (Special Signs)
ถ้าเจอ "เจ๊าะ": ในวัยเรียน/วัยรุ่น = มีปัญหาทางเพศ, ถูกเอาเปรียบ, ปัญหากับเพศตรงข้าม
6. Cheating & Affair Analysis (ความเจ้าชู้)
6.1 เกณฑ์หมกยก (Charm/Affair)
หาก ฐานคู่ หรือ ธาตุคู่ครอง ตกสถานะ "หมกยก (Bath)" (หมายเลข 2)
ผลทำนาย: เจ้าชู้, มีเสน่ห์แรง, (ถ้าเป็นธาตุแฝง = เจ้าชู้เงียบ)
6.2 เกณฑ์ภาคีเยอะ (Multiple Combinations)
หาก ฐานคู่ (วัน) ไปภาคีกับ ปี/เดือน/ยาม หรือ ธาตุคู่ครองมีการภาคีหลายจุด
ผลทำนาย: คู่ครองมีเพื่อนมาก (ชายมาก/หญิงมาก)
6.3 เกณฑ์คู่นั่งลาภ (Multiple Lovers)
Logic: เช็คจากตาราง "คู่ครองนั่งลาภ" (เช่น ชาย 甲乙 นั่ง 甲辰)
ผลทำนาย: มีโอกาสคู่ครองมีคนรักมากกว่า 1 คน
6.4 เกณฑ์ถ่ายเทหมกยก/เจ๊าะ + ภาคี (Specific Affair Rules)
Logic: ตรวจสอบดิถี และตัวถ่ายเทตามตาราง (เช่น ชาย 乙 ถ่ายเท 巳/申)
ผลทำนาย: มีโอกาสเจ้าชู้ คบซ้อน มีกิ๊ก
6.5 เกณฑ์ฐานคู่ "แป่" + ภาคี (Traveling/Distance Affair)
Logic: ฐานคู่เป็น "แป่" และมีการฮะ (เช่น ชาย 丙 ฐาน 申 ฮะ 巳)
ผลทำนาย: มีคู่ครองมากมาย, คบซ้อน
7. Spouse Characteristics ( ลักษณะคู่ครอง)
7.1 รูปร่างหน้าตา (Appearance)
ดูจากธาตุคู่ครอง (บน/ล่าง):
ไม้: สูงโปร่ง

7.2 อายุ (Age Difference)
สัมพันธ์กับ "ปี" (กุ้ยนั้ง/เชี่ยงแซ): อายุมากกว่า / มาจากทางไกล
สัมพันธ์กับ "ยาม" (กุ้ยนั้ง/เชี่ยงแซ): อายุน้อยกว่า
สัมพันธ์กับ "เดือน" (กุ้ยนั้ง/เชี่ยงแซ): อายุไล่เลี่ยกัน / เพื่อนเรียน / เพื่อนงาน
ไม่สัมพันธ์เลย: อายุไล่เลี่ยกัน
"ผั่ว" กัน: อายุห่าง 4-5 ปี หรือ เป็นหม้าย/มีตำหนิ
7.3 เชื้อชาติ (Nationality)
ต่างชาติ: ฐานคู่/ธาตุคู่ เป็น "แป่" (7) หรือ สัมพันธ์ดีกับ หลักปี
7.4 ฐานะ (Status)
ฐานะดี: คู่ครองนั่ง "ลาภ" หรือ "ไฉ่โข่ว" (คลัง) (ดู List ตารางคู่ครองมีฐานะ)
